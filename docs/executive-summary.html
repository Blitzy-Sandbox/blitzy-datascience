Rule Effect Enforced In
Rule 1Single HTTP clientapi/nba_client.py

Rule 3Required headers on every GETconfig.py + nba_client.py

Risk Likelihood Mitigation
NBA Stats API schema driftMediumInvariant tests + schema normalizer guard
HTTP 429 during peak trafficMediumProactive ≥ 1.0s floor + tenacity backoff with jitter
Interrupted runs losing progressLowCheckpoint-after-every-pull written to output/checkpoint.json
Single failing GAME_ID crashes pipelineLowRule 6 fail-safe iteration in ingest_games.py
Silent upstream package upgradeLowUpper-bounded pins in requirements.txt
